# My 60-Day JavaScript → TypeScript Journey

Welcome to my **60-Day JavaScript-to-TypeScript Journey**.

This repository documents my journey from strengthening my **JavaScript fundamentals** to becoming comfortable building applications with **TypeScript**.

I am not trying to rush through the language syntax. The goal is to understand **why things work**, write better code, make mistakes, debug them, and gradually build the confidence to use TypeScript in real projects.

---

## 🎯 My Goal

Over the next 60 days, I will move from JavaScript fundamentals to practical TypeScript development.

By the end of the journey, I want to be able to:

- Understand JavaScript fundamentals deeply
- Write clean and readable JavaScript
- Understand how JavaScript behaves at runtime
- Work confidently with arrays, objects, functions, and loops
- Understand asynchronous JavaScript
- Work with APIs
- Understand the DOM and browser environment
- Use modern JavaScript features
- Understand TypeScript's type system
- Create interfaces and type aliases
- Work with generics
- Understand unions, intersections, and narrowing
- Configure a TypeScript project
- Use TypeScript with JavaScript libraries
- Build practical projects with TypeScript
- Use TypeScript confidently in React projects
